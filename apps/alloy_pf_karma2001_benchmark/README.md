# alloy_pf_karma2001_benchmark

Frozen Karma (2001) alloy phase-field benchmark. Independent of
`apps/alloy_pf_directional`. Binary: `alloy_pf_karma2001_benchmark_openmp`.

Build through `./scripts/build.sh` at the repo root. LUMI helpers live in
`scripts/`. Figure data: `data/karma2001_fig1_present.tsv` and
`data/karma2001_fig2_present.tsv`.
